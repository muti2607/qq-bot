# QQ 定时发布机器人

每天按你设置的时间，把**文字 / 图片 / RSS 最新内容**自动发到你选择的 **QQ 群** 或 **私聊**。
所有内容、时间、目标都在网页后台（WebUI）里设置，部署在阿里云轻量（2 核 2G）上够用。

```
┌──────────────┐   HTTP(3001)   ┌──────────────────┐   扫码登录    ┌─────┐
│ 管理后台+调度 │ ─────────────▶ │ NapCat (QQ 协议端) │ ◀─────────── │ QQ  │
│ FastAPI :8080 │                │ OneBot11 :3001    │              └─────┘
└──────────────┘                └──────────────────┘
       ▲ 浏览器（SSH 隧道访问）
```

---

## 一、服务器部署（阿里云轻量 2C2G，约 10 分钟）

### 1. 上传代码

在你自己电脑上把整个 `qq-bot` 目录传到服务器：

```bash
# 方式一：scp
scp -r qq-bot root@你的服务器IP:/root/

# 方式二：git（如果你推到了仓库）
git clone 你的仓库地址 /opt/qq-bot
```

### 2. 一键安装并启动

```bash
cd /root/qq-bot
sudo bash deploy/install.sh
```

脚本会自动：安装 Docker（阿里云镜像源）→ 配镜像加速 → 复制到 `/opt/qq-bot` → 构建并启动 NapCat 和机器人 → 设置开机自启。

> 内存提示：NapCat（NTQQ）常驻约 400–700MB，机器人约 120MB，2G 内存足够；
> 若同时装了 Java 等占内存的服务，建议加 1–2G swap：
> `fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile && echo '/swapfile none swap sw 0 0' >> /etc/fstab`

### 3. 从自己电脑打开端口（SSH 隧道）

为了安全，管理后台（8080）和 NapCat WebUI（3000）**只监听服务器本机**，不暴露公网。
在你自己的电脑上执行（Windows 用 PowerShell / CMD 也行）：

```bash
ssh -N -L 3000:127.0.0.1:3000 -L 8080:127.0.0.1:8080 root@你的服务器IP
```

保持这个窗口不要关。

### 4. 扫码登录 QQ

1. 浏览器打开 http://127.0.0.1:3000/webui/
2. 用**手机 QQ 扫一扫**登录（建议用一个专门的小号，别用主号）
3. 登录成功后，点 WebUI 左侧「网络配置」，确认有一个 `HTTP 服务 0.0.0.0:3001` 且已开启。
   如果列表是空的：把 `deploy/onebot11.example.json` 复制到 `napcat/config/onebot11_你的QQ号.json`，
   然后 `docker compose restart napcat`（见下方「常见问题」）。

> NapCat 的 HTTP 接口没有开 token 时，同网络内的容器都能调用。本 compose 没有把 3001 映射到宿主机，
> 只给机器人容器用，相对安全；如果你在 NapCat WebUI 里给 HTTP 服务设了 token，
> 记得在机器人后台「设置 → OneBot Access Token」里填一样的值。

### 5. 打开管理后台

浏览器访问 http://127.0.0.1:8080

- 右上角「设置」→ **立刻设置管理密码**（设置后要重新登录，防止别人误操作）。
- 「OneBot 地址」默认已经是 `http://napcat:3001`（compose 通过环境变量预置），不用改。
- 顶部状态点变绿、显示你的 QQ 昵称，就说明打通了。

## 二、怎么用

### 新建任务

点「任务列表」右上角 **＋ 新建任务**：

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 只是给你自己看的，比如「每日早报」 |
| 内容来源 | ① 固定文本 ② RSS 只发文字 ③ RSS 文字+链接 |
| 正文 | 占位符 `{date}` `{time}` `{datetime}` `{weekday}` `{name}` `{quote}`（随机名言）；倒计时 `{days:1209}` `{days:2027-03-01}` `{label:1209}` `{weekday_of:1209}`（发送时自动计算剩余天数，月日若今年已过自动顺延到明年）；算式 `{=115-30}` `{=(365+1)*2}`（支持 + - * / // % ** 括号）；自定义变量 `{变量名}` |
| 自定义变量 | 任务里可定义任意「名=值」，正文用 `{名}` 引用，如 `赛季=UC`、正文 `{赛季}赛季` |
| 配图方式 | 不配图 / 固定一张 / 随机抽取（可选候选池，不选则全图片库随机） |
| @全体成员 | 打开后群消息开头会 @全体（私聊无效果） |
| 发送目标 | 下拉选群 / 好友，点「添加」；也可以直接填 QQ 号加私聊 |
| 群组预设 | 把常用的一批群/私聊存成预设（如「比赛通知组」），建任务时点「载入预设」一键添加；「把当前目标存为预设」随时更新 |
| 发送时间 | 两个下拉选择「几点几分」，即每天该时刻发送；也可以直接写 cron |

常用 cron 写法：

| 表达式 | 含义 |
| --- | --- |
| `0 9 * * *` | 每天 09:00 |
| `30 8 * * 1-5` | 周一到周五 08:30 |
| `0 20 * * 0` | 每周日 20:00 |
| `0 9 1 * *` | 每月 1 号 09:00 |

> ⚠️ 标准 cron 不能表达「每 2 天」这类跨月间隔；需要的话可以用两个任务（如 `0 9 */2 * *` 隔日发）。

### 触发回复（@机器人 + 关键词）

后台「触发回复」面板可添加：触发词、回复内容（支持全部占位符，包括倒计时/算式/变量/`{quote}`）、
是否必须 @机器人、生效范围（所有群/指定群/仅私聊）、冷却秒数、配图（固定或随机池）、
**随机名言**（关闭 / 正文后附一句 / 只回复名言）。
例如设置触发词「考核」后，群里有人 `@机器人 考核` 就会回复「距离1209考核还有 {days:1209} 天」。

名言池在「设置 → 名言池」里自定义（每行一条，格式 `内容|出处`）；右侧卡片轮播、
`{quote}` 占位符、触发回复的随机名言都用它。内置 70+ 条默认名言，可一键恢复。

**需要 NapCat 配置一次消息上报**：WebUI → 网络配置 → 添加 **HTTP POST**：

| 项 | 值 |
| --- | --- |
| URL | `http://qq-daily-bot:8080/post` |
| HTTP Headers | `Authorization: Bearer 上报Token`（与后台「设置 → 事件上报 Token」一致；两边都留空则不校验） |
| 事件订阅 | 开启 group / private 的 message 事件 |

保存后重启 NapCat（`docker compose restart napcat`）生效；每次触发的回复都会写入运行日志。

### 立即执行 / 测试

- 任务卡片左边的蓝色 **立即** 按钮：马上发一次给你设置的目标。
- 编辑窗口里的「预览」：不发送，只看最终内容长什么样。
- 「立即发送到所选目标」：先保存再发送，用来验证群/好友是否选对。

### 图片库

页面底部「图片库」上传图片（png/jpg/gif/webp，≤10MB），然后在任务里选「配图」。
发送时图片以 base64 传输，不依赖服务器文件路径。

### 运行日志

右侧「运行日志」实时刷新（SSE），每次发送成功/失败都会记录到分钟级时间 + 原因，
排错就先看这里。

## 三、务必注意的坑

1. **协议端合规**：NapCat 属于第三方 QQ 协议端，非腾讯官方接口。用小号、控制发送频率
   （本程序每天几条完全没问题），别群发广告，否则可能被风控 / 封号。
2. **微信/QQ 版本**：NapCat 更新较勤，拉最新镜像一般即可；登录掉线会自动重启容器，
   严重时 WebUI 里重新扫码。
3. **阿里云安全组**：默认**不需要**开放 3000/8080（走 SSH 隧道最安全）。
   如果你确实想直接用公网 IP+端口访问后台，需要：
   - 安全组放行你的固定 IP → 8080；
   - 把 `docker-compose.yml` 里 `127.0.0.1:8080:8080` 改成 `8080:8080`；
   - **必须**先设置管理密码。
   国内服务器开 80/443 需要域名备案，所以这里用的是 8080，不用备案。
4. **数据备份**：所有数据在 `data/`（`bot.db` 任务配置 + `uploads/` 图片），
   `napcat/qq` 是 QQ 登录态。定期 `tar czf backup.tgz data napcat/qq` 即可。

## 四、常见问题

**Q：设置里状态一直显示“未连接 OneBot”？**
- 确认 NapCat 已扫码登录（WebUI 显示在线）。
- NapCat WebUI → 网络配置 → 添加/确认「HTTP 服务」，端口 3001，Host 0.0.0.0。
- 在服务器上测：`docker compose exec bot python -c "import httpx;print(httpx.post('http://napcat:3001/get_login_info').text)"`
- 如果地址写的是 `http://127.0.0.1:3001`，那是错的方向——机器人在另一个容器里，要用 `http://napcat:3001`。

**Q：发送报错 `send_group_msg 返回 HTTP ...`？**
多半是 QQ 掉线或被风控。看 `docker compose logs -f napcat`，必要时重新扫码。

**Q：图片发不出去？**
检查图片 < 10MB，且任务里选中的图片仍存在于图片库（删图会自动解除引用）。

**Q：想改端口？**
`docker-compose.yml` 里改映射，如 `"0.0.0.0:9000:8080"`，然后 `docker compose up -d`。

**Q：怎么更新代码？**
覆盖文件 → `cd /opt/qq-bot && docker compose up -d --build`。数据在 `data/`，不会丢。

## 五、目录结构

```
qq-bot/
├── main.py               FastAPI 接口 + 登录鉴权 + 静态页
├── scheduler.py          APScheduler 定时任务（每个任务一条 cron job）
├── sender.py             内容渲染：文本模板 / 图片 / RSS 抓取
├── onebot.py             OneBot11 HTTP 客户端
├── db.py                 SQLite 数据层（任务、目标、图片、日志、设置）
├── static/index.html     管理后台（单页，无构建）
├── static/login.html     登录页
├── data/                 运行时数据（自动生成，注意备份）
├── Dockerfile / docker-compose.yml
├── deploy/               一键安装脚本、NapCat 配置样例、nginx 反代、systemd
└── _selftest*.py         自测脚本（用内置 mock 跑完整发送链路，不会真的发 QQ）
```

## 六、本地开发（Windows）

双击 `run-windows.bat` 即可（会自动建虚拟环境装依赖），
然后访问 http://127.0.0.1:8080 。
想在本机调试发送，可把「设置 → OneBot 地址」指向本机已登录的 NapCat（`http://127.0.0.1:3001`）。

不装 NapCat 也能验证代码是否正常（会起一个假的 OneBot，只在内存里记录“发了什么”）：

```bash
.venv/Scripts/python.exe _selftest.py       # 发送链路 / 调度 / 模板 / 图片
.venv/Scripts/python.exe _selftest_rss.py   # RSS 抓取与拼装
```
