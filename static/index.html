启用「触发回复」需要在 NapCat WebUI → 网络配置 → HTTP POST 里新增一条： 地址 http://qq-daily-bot:8080/post， HTTP Header 加 Authorization: Bearer 与上面一致， 事件订阅勾选「消息事件」（group / private 的 message）。
