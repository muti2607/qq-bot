远程上传接口（图片会直接进图片库）：
POST /remote/upload　JSON：{"filename":"a.png","data":"<base64>"}
POST /remote/upload-file　multipart 文件域 file
GET /remote/ping　连通性测试
头部带 Authorization: Bearer 与上面一致。限制：单张 ≤10MB； 每 IP 每 60 秒最多 20 次请求，连续超限 3 次封禁 10 分钟（防 DoS）。示例： curl -X POST http://服务器:8080/remote/upload -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" -d '{"filename":"x.png","data":"<base64>"}'
